How it learns

Corrections, confirmations and comments (web, Telegram, chat) are stored as feedback. Each corrected or confirmed email becomes a regression test. The optimizer proposes a new playbook of rules; it is replayed against every test and only kept if the score does not drop and nothing that used to be right breaks. You then approve it (or it is applied automatically if enabled) and invoices still needing a check are re-read with the new rules. Fields you corrected by hand are never overwritten.
